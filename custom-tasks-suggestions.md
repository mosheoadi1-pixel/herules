## Tips for Adding to the CSV

1. **Hebrew first**: Every entry has Hebrew (`he`) and English (`en`) - the app defaults to Hebrew RTL
2. **Categories matter**: The category determines how the task appears in the app
3. **Intensity 1-3**: 1 = light/playful, 2 = moderate, 3 = intense/full power exchange
4. **Tags**: Use existing tags or create new ones that fit - they filter and group tasks
5. **Minutes**: Realistic time ranges - from 1 minute to 1440 (24 hours)
6. **The "her is center" principle**: Every task should ultimately center her pleasure, command, or presence

To actually add these to the template, you'd append them to `custom-tasks-template.csv` maintaining the exact format. The file uses `CREATE TABLE IF NOT EXISTS` semantics conceptually - new rows don't break anything, they just get added to the pool.
